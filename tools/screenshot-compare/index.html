Reliable comparisons

Use matching data, dates and UI state. Crop both screenshots to the screen content; borders and desktop chrome distort width matching. Alignment translates and uniformly scales—never stretches one axis. A single anchor does not establish scale. Pixel difference also includes font rasterization and data differences; it is not a correctness score.
