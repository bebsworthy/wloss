# Description

Implement bundled USDA/Ciqual food catalogs and persistent Open Food Facts barcode data with explicit nutrient semantics, quantities, provenance and immutable revisions. Includes reproducible downloads, normalization, offline search, migration, cache/update behavior and offline backup/restore; integrates with WLO-0157 for ingredient-based recipe nutrition. Full acceptance contract is in the spec. Source-ranking and carb-convention decisions remain open on WLO-0159.
