# Objective
Provide an optional expert comparison of smoothing methods without affecting the canonical trend.

# Prerequisites
WLO-0054 and dogfood evidence that comparison is useful.

# Scope
- Overlay methods using identical source events, scalar policy, and chart window.
- Use a clear legend, accessible series descriptions, and documented revision/lag behavior.
- Keep comparison transient unless a separate explicit ruling permits changing the canonical default.

# Acceptance
Series cannot mix inputs/windows; TalkBack can distinguish them; sparse and recent-value revision states are explained; chart performance remains acceptable on long histories.
