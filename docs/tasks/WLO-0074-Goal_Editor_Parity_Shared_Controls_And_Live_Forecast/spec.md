# Objective
Use one goal-editing model after onboarding, with immediate and honest forecast feedback.

# Prerequisites
WLO-0052, WLO-0068, and WLO-0073.

# Scope
- Reuse the onboarding goal concepts, validation, pace controls, and production forecast engine; remove the second primitive form model.
- Edit current weight context, target, pace, and optional date in the active unit without conversion drift.
- Show implied pace and forecast eligibility/range before saving.
- Save one auditable target-document version.
- Support every goal mode approved by WLO-0068.

# Acceptance
Identical inputs produce identical validation and forecast in onboarding and Settings; one save creates one version; invalid/held states explain themselves; kg/lb and process recreation are tested.
