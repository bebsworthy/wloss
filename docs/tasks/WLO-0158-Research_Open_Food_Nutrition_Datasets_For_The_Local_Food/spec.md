## Scope and completed research

Findings: docs/research/open-food-nutrition-data.md (2026-09-19).

Preserve dataset-specific nutrient semantics, source revisions and missing-value states. No dataset selection ruling or application change was made.

Acceptance: comparison, licence/access details, local-first recommendation, model implications and source links recorded. Complete. Full dataset quality/coverage and packaged-size measurements remain implementation work, explicitly outside this documentation research.
