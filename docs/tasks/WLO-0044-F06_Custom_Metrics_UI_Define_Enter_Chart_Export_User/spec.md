# Objective
Later, provide arbitrary quantified-self metrics without weakening the weight-first product or inventing an unstable schema contract.

# Prerequisites
The release-1 weight loop is dogfood-stable and evidence shows demand beyond built-in measurements.

# Contract work before UI
- Stable metric/type IDs independent of display names.
- Dimension, canonical unit, allowed display units, precision, finite/range validation, and missing-value rules.
- Rename, archive/unarchive, collision, reserved-name, delete, and restore semantics.
- Stable CSV/JSON column identity and round-trip compatibility across renames.

# UI after the contract
Material 3 registry/list, entry, chart, history, and export surfaces reusing proven weight patterns without adding generic framework layers to F06.

# Acceptance
Define → enter → rename → chart → export → restore retains identity and values; archived metrics remain recoverable; invalid units cannot mix; accessibility and long-list behavior are tested.
