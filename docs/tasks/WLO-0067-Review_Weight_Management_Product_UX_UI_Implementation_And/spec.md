# Objective

Critically review WLO's weight-management experience as the product's current focus, covering governing product docs, market research, feature specs, design system, mockups and user flows, current Android UI and implementation, and all ToDo tickets.

# Deliverable

A prioritized, evidence-based action list aimed at making WLO the best weight tracker available, with critique of backlog scope, sequencing, gaps, duplication, and acceptance criteria. This review does not implement product changes.

# Review criteria

- Preserve local-first, provenance, weak-data-held, shame-free, and free/open-source rulings.
- Prefer Material 3 components and Android best practice without unnecessary abstraction.
- Evaluate the complete measurement loop: onboarding, capture, correction, history, trends, goals/forecast, explanation, reminders, export/restore, and accessibility.
- Distinguish table stakes from defensible differentiation.
- Rank actions by user value, risk reduction, dependency order, and effort.
- Cite concrete docs, screens, code, tests, and tickets.
