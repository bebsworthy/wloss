# Optional body measurements — interactive proposal

Open measurements.html. Uses the same Inter assets and 470 × 1045 desktop preview dimensions as the recent goal mockup.

Flows: Weight entry → measurement overview → individual history; record a subset → add optional fields → save back to overview; first-use empty state; optional body-fat field during a manual weigh-in. Left/right limb fields are explicit. Imported scale readings are labelled by source; sync itself is not implemented.

All values are fictional and session-local. Chart/history are illustrative; range buttons explain the fixed 90-day preview. Weight entry and sync are examples, not production storage. Tape calculation is not implemented here. Actual measuring guidance and source-separated charts require a subsequent specification. No app changes.

Verified in Chromium: page renders without JS errors; overview opens detail; single-field waist save succeeds with hips/chest blank. Screenshots overview.png, detail.png, record.png, empty.png.
