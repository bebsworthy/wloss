Self-review — design bar & spec checklist (flow 04 · F06)

Design bar
  1. Provenance chips on every derived number — trend (derived · EWMA α 0.15, R-A2), raw weight (measured · scale), body-fat (estimated · impedance ±3–4 %, honest uncertainty), ribbon (derived area). None missing; measured and estimated never silently merged. ✓
  2. Tone — “keep or correct?”, “keep weighing — trend forms in a few days”. Deltas described, never judged; “over”, “missed”, “welcome back, you gained” absent from every string. ✓
  3. No red / gains neutral — gain-day variant uses neutral-delta with the identical tick and motion; the outlier guard renders flat. ✓
  4. R-U15 — three equal paths on one surface; the pad is prefilled, back-datable, one tap from either assist; OCR failure lands silently on the pad. ✓
  5. Discretion ladder (F06 side) — discreet-mode eye, lock-screen dots (flow 01), BMI on request; the Archive half of the ladder (gate, FLAG_SECURE, silent shutter) lives in flow 09. ✓
  6. Local-first — “on-device OCR · no cloud”; no spinner, no network state anywhere. ✓

Spec micro-interactions honored (F06)
  1. Odometer numerals: trend hero rolls digit-by-digit, 400 ms, tabular digits — confirmation card + Hub hero. ✓ (noted, static by medium)
  2. Progress ribbon: area between trend and N-days-ago; thickness breathe 200 ms on new data; accent band above / neutral half shown where a day pops above the reference. ✓
  3. Back-fill: long-press chart → pad → zero-phase recent values re-settle with a visible 300 ms ease; editing history honest and visible. ✓
  4. Confirmation haptics: single soft tick on save; gain = same tick, same motion, neutral color; OCR lock = brackets snap green + value flies. ✓
  5. Frozen orders respected: F06 confirmation anatomy (trend → raw small → ribbon), the ≥3-points-in-7-days trend gate, R-B8 re-weighs join quietly. ✓
