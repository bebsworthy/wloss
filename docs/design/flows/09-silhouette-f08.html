Capture detail — flags are facts, deletion is final.
  1. 19The flag names its reason and its consequence in one line (“excluded from delta claims”) — a data-quality fact, never a grade. Partial captures (one angle) read the same way and are excluded only from angle-complete comparisons.
  2. 20Delete is a shred: outline, width profile, and derived rows destroyed irreversibly. Because of R-U16 there is no photograph to delete — the most sensitive artifact in the app is the one that cannot exist. History is never gated, blurred, or capped while it exists (anti-paywall).
  3. 21“Set as reference” is the only way a reference changes — user-tapped here or by long-press in the grid; the app never picks one. Everything downstream (delta card, compare studio, per-band deltas) re-anchors to the user’s choice.

Self-review — design bar & spec checklist (flow 09)

Design bar
  1. R-U16 — checked again, now across seven mocks. No img element, no photograph placeholder, no gallery idiom in any state: the viewfinder shows gradient + skeleton; thumbnails, delta card, compare studio, and profile charts are stroke-path vectors and derived series; empty and “Collecting” states use dots. The outline is the artifact; nothing to leak. ✓
  2. Provenance trio — tape values measured, outline deltas derived (width profile), any future circumferences estimated with bands — badged separately, never merged (mock 6). ✓
  3. Tone — photographic verbs only (capture / reference / develop / compare); “trouble spots”, “missed”, “over” absent; flags are named data, never grades (mock 7). ✓
  4. No red — the failing skeleton segment renders held-amber with its named fix; grid markers are neutral. ✓
  5. R-U7 + R-D9 — the section says “Archive” with the abstract stacked-outline glyph; nothing in nav, notifications, or exports says body/photo/silhouette. ✓
  6. R-U13 — gaps render as faint dots and are never mentioned again; coverage (“11 of the last 12 weeks”), not duty; “Not this week” reschedules silently (wireframe 5). ✓
  7. Sensitive-surface protection — biometric gate on every entry, auto-relock, FLAG_SECURE, silent shutter always, generic reminder copy, and deep links land on the gate. F06 weight values remain directly readable by design. ✓
  8. Local-first — no network state anywhere in the flow; exports can contain no photographs because none exist. ✓
