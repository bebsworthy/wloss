Self-review — design bar & spec checklist (flow 06)

Design bar
  1. Provenance everywhere — every grade carries inputs + rubric version + quality score (panel 8); classifier confidence shown at capture and stored on the entry (16, 22); baselines carry their trailing window (26); correlation gates named (F09 14-day ring, F11 n ≥ 21). No derived number renders bare. ✓
  2. Tone — describe the data, never the person — Gut’s dash says “collecting”, never a verdict; “B, from 4 weigh-ins” as the model sentence; “a quiet week, not a crisis”; “unusual for you”. F11 banned list (failed / cheat / bad / guilt) and F09 banned list (overdue / failed / abnormal) — both clean in all UI strings; app-wide list respected too. ✓
  3. No-red discipline — held is amber (the strongest state color that exists); the Bristol ideal zone is a halo, i.e. education by placement, not a verdict; the doctor card is calm warm-tint, one per episode, “show a doctor” as the only action; no alarm hue anywhere. ✓
  4. R-U7 — nav, rail, tile, and the (annotated) notification all say “Digestion”; renamable; taboo words confined to inside the feature. ✓
  5. R-U13 — quiet days render dashed in the heatmap and drive the frequency line; the gut is absent from every completeness model (its own report-card slot is a dash); gap reminders are personal-baseline-gated and default off. ✓
  6. Rulings — R-U2 report day = check-in day (→ flow 03, link also on the streak chip → flow 01); R-U3 dormant tile; R-U4 Wrapped [v1.x]; R-U10 oracles + held-neutral + freeze verbatim + free repairs. ✓
  7. Local-first — grades, stats, share render (~200 ms), and the classifier are all on-device deterministic; no spinner, no cloud state anywhere in the flow. ✓
  8. Density — six mocks answer their questions above the fold at 390×844; whitespace spent only at the share preview and the reveal grid. ✓
