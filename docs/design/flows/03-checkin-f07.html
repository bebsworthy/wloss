Self-review — design bar & spec checklist (flow 03)

Design bar
  1. Provenance chips on every derived number — trend (derived ⓘ), burn (measured, engine transparent-v1), proposal (adaptive template re-derivation), ring target (updates weekly · Sep 6 → re-stamps Sep 13), held estimate (frozen at last good), breakdown terms (each cited). None missing. ✓
  2. Tone — “on pace”, “6/7 days logged”, “none this week — it re-opens when the data does”. Plateau framing = adaptation (“your physiology adapting, and the plan follows”; Adjustment glow as “quiet applause”); the body is never stubborn, no “over budget”, no verdict words anywhere in mock copy. ✓
  3. No red — held renders amber with a single 600 ms pulse; deltas use neutral/accent only; the strongest color in the flow is amber. Red is reserved for nothing. ✓
  4. R-U13 — Wednesday’s fast is a chosen state (blue dot), Sunday is “still open” with a one-tap fix; day statuses never shamed, gut absent from the completeness model. ✓
  5. Local-first, stated once — “Computed on your device” appears on the check-in card only (F07 §9); no spinners, no network states, works in a bunker. ✓
  6. Ledger + reversibility — Apply appends entry #13 with an input snapshot; “tap to revert” on the ledger line and one-tap revert in the Studio; reverts write forward, history immutable. ✓
  7. Published constants — 7,700 kcal/kg · 3,500/lb (R-A1) shown in the breakdown formula with the Algorithms-page chip and “reproduce it yourself”; rough days excluded by name. ✓
  8. Hedged dates — the only dates outside the calendar (next check-in, forecast re-bloom) carry “an estimate, not a promise”; the cone itself lives in flow 07. ✓
  9. No dismiss-shame; no missed-Sunday guilt — swipe away = Keep; a skipped check-in persists 7 days with the engine still computing, next check-in covers the elapsed window, nudges never escalate. ✓
