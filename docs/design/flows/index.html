Reading notes

Conventions
  1. Values shown are persona data, consistent inside each flow (and across 01/03/04/06/08/09: one week of one user).
  2. Amber circular pins on each mock map to numbered annotations beneath it; motion/haptic values quote DESIGN-SYSTEM §4–5 verbatim.
  3. Wireframes come first on every page; mocks are the reviewable surface.
  4. Only shared primitives style the mocks (_wlo.css = DESIGN-SYSTEM §1–§5 as CSS) — no per-flow colors exist.
