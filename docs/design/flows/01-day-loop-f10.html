Self-review — design bar & spec checklist (flow 01)

Design bar
  1. Provenance chips on every derived number — trend (derived · EWMA), ring (updates weekly · Sep 8), plan calories (planned), expenditure (est ±30 %), diary entries (AI-est / DB-verified). None missing. ✓
  2. Tone — “720 left”, “+10 … inside daily variance”, “Lunch is still open — want to log it?”. No failed/missed/over-as-verdict; no self-congratulation (R-D15); banned list clean. ✓
  3. No red / no alarm — +10 kcal renders neutral-delta; urgency only via position (weigh card leads). No red token exists. ✓
  4. R-U7 naming — nav + rail say “Digestion” and “Archive”; no taboo words anywhere; notification copy generic. ✓
  5. R-U13 — Wednesday fast renders as a *chosen* state (dot legend), never a gap; gut is absent from any completeness model. ✓
  6. R-U15 — weigh-in card copy “Step on, snap, or type” states three equal paths up front. ✓
  7. Local-first — no spinner anywhere; offline never referenced as a state; “Computed on your device” on the check-in card. ✓
  8. Density — 4 cards answer 3 questions above the fold at 390×844; whitespace only at hero/ring. ✓
  9. Content-rendered cards (R-D14) — the no-plan variant renders no meals card and no empty state; absence is silent, a lapsed plan ends silently, F03 is never upsold from the day loop. ✓
  10. No self-congratulation (R-D15) — the brag sweep: “logged in 6 s”, “5-second photo path”, “under 1 s”, “two taps to done”, pre-emptive “works offline” all removed from screen copy; capability survives only as post-hoc fact (“worked offline — nothing left your phone”), affordances as instructions (“tap for history”). ✓
Spec micro-interactions honored
  1. Hero spring count-up ~600 ms; delta chip 150 ms pop (motion table §4.1) — annotated, static by medium.
  2. Ring 400 ms ease-out sweep + end tick; in-band evening landing = double micro-bounce + success haptic. ✓ (annotation)
  3. Rail 32 ms press-scale + tick; camera long-press = kcal quick-add. ✓
  4. Card collapse via swipe-up + 5 s undo — reserved for the diary slice card (not shown collapsed). ✓
  5. Nudge: silent channel, ≤2 actions, animated collapse, dismissal memory, one-tap pause. ✓
  6. R-U17 promotion shown; R-U9 recap in-app only. ✓
  7. No confetti on logging — celebration stays geometric (ring sweep only). ✓
Open items surfaced: streak-chip tick values unspecified in spec → design-system default (150 ms pop) applied.
