The overlay places the main divider, capsule, field, slider and Save at the reference positions, within normal subpixel rounding/rasterization.

The fixture changes only reference headline values and, in Intake mode, the translated amount/slider labels to match the emulator's 1,776 maintenance, 1,276 intake and 77.1→74.0 goal. The engine stops each trajectory at the goal, so it does not draw an invented continuation below the target. The approved handoff explicitly requires production forecast output rather than the demo equation. This is the reason for the chart-data differences, not a substituted layout.
